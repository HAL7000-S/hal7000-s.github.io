Bayesian MCMC Demo

コイン投げの観測から、表の出る確率 θ をランダムウォークMetropolis法で推定します。青いヒストグラムと赤い理論曲線を比べてみてください。毎回、異なる乱数で計算します。

コイン投げを、ベイズ推論で

事前分布
θ ∼ Beta(1, 1)
観測
n回のコイン投げで、表がH回
事後分布
θ | H, n ∼ Beta(H + 1, n − H + 1)
理論平均
E[θ | H, n] = (H + 1) / (n + 2)

対数事後密度は H log θ + (n − H) log(1 − θ)（定数を除く）。θ′ = θ + σZ、Z ∼ N(0, 1) を提案し、事後密度の比に従って採択します。0 < θ′ < 1 の外は棄却します。

観測とサンプリングの設定

n：1〜100の整数、H：0〜nの整数
σ：0より大きい有限値、反復回数：100〜100,000の整数

Markov連鎖のトレース

グラフの表示にはCanvas対応ブラウザーが必要です。

横軸：反復番号 ／ 縦軸：θ。トレースにはburn-inを含む全反復を表示し、描画点だけを間引いています。薄い背景は除外する最初の20%です。

最初の20%をburn-inとして除外するのは便宜的な設定であり、収束を保証するものではありません。採択率だけでも収束は判断できません。σや反復回数を変えて、トレースと理論分布を比較してください。
